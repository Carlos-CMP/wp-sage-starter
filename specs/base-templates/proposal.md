# Base Templates

## Intent

Make the starter usable beyond the demo homepage by providing minimal generic templates for core WordPress views.

## Scope

- Page, single, index/archive, search, and 404 templates.
- Shared page header and content partials.
- Empty states and pagination.
- Design-system classes only; no project-specific layout assumptions.

## Out Of Scope

- Custom post type templates.
- Sidebar-dependent layouts.
- Project-specific archive designs.
- Complex search filtering.

## Decision

Templates will stay minimal and generic, using shared header/footer from the layout and neutral content wrappers.
