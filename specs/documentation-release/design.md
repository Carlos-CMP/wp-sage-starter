# Documentation Release Design

## Files

- `docs/BLOCKS.md`: folder contract and minimal steps for a new block.
- `docs/PROJECT-CONFIG.md`: environment, tokens, menus, site-content feature flags, hooks, and validation.
- `README.md`: links to docs.
- `CHANGELOG.md`: current v1.0.0 contents.
- `specs/documentation-release/tasks.md`: status, including tag blocker.

## Validation

- Run `scripts/validate.ps1`.
- Verify docs contain bootstrap, ownership, block creation, design tokens, feature flags, secrets, and validation references.
